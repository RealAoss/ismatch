# ismatch

**مطابقة الأسماء العربية مهما اختلفت كتابتها أو أبجديتها.**

`محمد` = `Mohammed` = `Muhammad` = `Mohamed` = `מוחמד`، لكن `حسن` ≠ `حسين`.

مكتبة بايثون خالصة، بلا أي اعتماديات، وتعمل بدون إنترنت. [English](README.md)

</div>

```python
>>> import ismatch
>>> ismatch.is_match("محمد عبد الرحمن الخطيب", "Dr. Mohamed Abdelrahman Al-Khatib")
True
>>> ismatch.is_match("Hassan Ali", "Hussein Ali")
False
```

## لماذا هذا المشروع؟

الاسم العربي الواحد يُكتب بالحروف اللاتينية بعشرات الأشكال الصحيحة، ولا يوجد
معيار واحد: الكتابة تتغيّر حسب البلد واللهجة واللغة الأجنبية السائدة والموظف
الذي أدخل الاسم. والبرامج التي تقارن الأسماء كنصوص عادية تخطئ في الاتجاهين،
ويدفع الثمن أناس حقيقيون:

- **المستشفيات والعيادات** تنشئ ملفين للمريض نفسه فينقسم تاريخه الطبي.
- **تسجيل اللاجئين ولمّ شمل العائلات** يفشل في ربط أقارب سُجّلت أسماؤهم لدى جهات
  مختلفة بأبجديات مختلفة.
- **البنوك وقوائم العقوبات** تجمّد حسابات أبرياء لأن اسمهم «يشبه» اسماً مدرجاً،
  فالمطابقة التقريبية العامة لا تفرّق بين «حسن» و«حسين».
- **الأنظمة الحكومية والجامعية** لا تستطيع ربط السجل العربي بنظيره المكتوب
  كما في جواز السفر.

الحلول الجيدة موجودة لكنها تجارية أو ثقيلة أو تدعم الحروف اللاتينية فقط.
`ismatch` مكتبة صغيرة يمكن قراءة كودها في جلسة واحدة.

## ماذا تفهم؟

- الحركات غير المكتوبة: `محمد` ↔ Mohammed / Muhammad / Mohamed
- عادات الكتابة حسب المنطقة: `جمال` ↔ Jamal / Gamal / Djamel
- الحروف المتقاربة: `عثمان` ↔ Othman / Osman، `القذافي` ↔ Qaddafi / Gaddafi
- أسماء «عبد» المركّبة: `عبدالرحمن` ↔ Abdul Rahman / Abd al-Rahman / Abderrahmane
- «ال» التعريف والحروف الشمسية: `السيد` ↔ El-Sayed، `السادات` ↔ as-Sadat
- بن / ابن / الألقاب / الحروف الأولى: `خالد بن الوليد` ↔ Khalid ibn al-Walid
- الأسماء الملتصقة والمنفصلة: `صلاح الدين` ↔ Salahuddin، `أبو بكر` ↔ Abubakar
- اختلافات الإملاء العربي: `أحمد`/`احمد`، `فاطمة`/`فاطمه`، `يحيى`/`يحيي`، التشكيل
- ترتيب الاسم وحذف الاسم الأوسط: "Hassan, Mohamed Ali" ↔ `محمد علي حسن`
- العربيزي: Mo7amed ↔ `محمد`
- الكتابة العبرية (تجريبي): `מוחמד` ↔ `محمد`

وما ترفض دمجه، وهو بنفس الأهمية:

- `حسن` ≠ `حسين` (حرف علة واحد)
- `محمد` ≠ `محمود` (الحروف الساكنة نفسها)
- `منير` ≠ `منيرة` (مذكر ومؤنث)
- `عبد الرحمن` ≠ `عبد الرحيم`، و`عبد الله` ≠ `عبد الإله`
- أحمد **محمد** علي ≠ أحمد **محمود** علي (جزء واحد مختلف = شخص آخر)

## كيف تعمل؟

1. **تحليل الاسم**: إزالة التشكيل والألقاب، فصل «ال»، دمج «عبد» مع ما بعدها.
2. **التحويل الصوتي**: كل جزء يتحوّل إلى أبجدية صوتية صغيرة مشتركة بين العربية
   والعبرية واللاتينية.
3. **المحاذاة**: مسافة تحرير موزونة تكاليفها مأخوذة من طريقة اختلاف الأسماء فعلاً.
4. **قاموس** من نحو 450 اسماً شائعاً يعطي الحركات التي لا تكتبها العربية ويعرف
   أن بعض الأسماء المتشابهة أسماء مختلفة.
5. **مطابقة أجزاء الاسم الكامل** مع تحمّل تغيّر الترتيب وحذف الأسماء الوسطى.

لا يوجد تعلّم آلي ولا تحميل نماذج: النتيجة ثابتة وكل درجة يمكن تفسيرها.

## الدقة

على مجموعة اختبار «عمياء» (2154 زوجاً، شُغّلت مرة واحدة ولم يُضبط المحرّك عليها):

| الطريقة | الدقة | الاستدعاء | F1 |
|---|---|---|---|
| Levenshtein | 0.662 | 0.552 | 0.602 |
| نقحرة + Levenshtein | 0.735 | 0.937 | 0.824 |
| **ismatch** | **0.996** | **0.968** | **0.981** |

**تنبيه صادق:** مجموعات الاختبار كتبها مؤلفو المشروع وليست بيانات حقيقية من
أنظمة فعلية، والبيانات الواقعية ستكون أصعب. إذا كانت لديك أزواج أسماء مصنّفة من
نظام حقيقي فمشاركتها هي أثمن مساهمة ممكنة.

## حدود يجب معرفتها

- **الاسم ليس هوية.** قد يتطابق اسما شخصين مختلفين تماماً؛ استخدم الدرجة مع
  تاريخ الميلاد أو رقم الوثيقة أو غيرها.
- في أي قرار يمسّ إنساناً (عقوبات، احتيال) يجب أن يراجع النتيجةَ إنسان.
- الأسماء غير الموجودة في القاموس تُطابَق بالقواعد فقط.
- دعم العبرية تجريبي، والصيغ الفارسية والأردية والتركية مغطّاة جزئياً.
