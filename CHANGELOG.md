# Changelog

## 0.1.0

First release.

- `compare`, `score`, `is_match`: cross-script comparison of full names
  (Arabic, Latin, experimental Hebrew) with an explainable result.
- `NameIndex` and `dedupe` for searching and de-duplicating lists.
- `keys`: script-independent blocking keys.
- `ismatch` command line tool and an in-browser demo (Pyodide).
- Lexicon of ~450 common Arabic names.
- Benchmark with development, validation and blind sets.
